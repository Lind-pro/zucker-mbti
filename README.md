# MBTI 在线性格测试工具

一个简洁美观的在线MBTI性格测试工具，帮助用户了解自己的性格类型。

## 功能特点

- ✅ **完整的MBTI测试**：包含60道精心设计的题目，覆盖E-I、S-N、T-F、J-P四个维度
- ✅ **16种性格类型**：提供所有16种MBTI性格类型的详细描述
- ✅ **直观的界面**：现代化的UI设计，流畅的用户体验
- ✅ **实时进度**：清晰的进度条显示测试进度
- ✅ **详细结果**：展示各维度的倾向百分比和性格类型详细描述
- ✅ **响应式设计**：完美适配桌面和移动设备
- ✅ **键盘快捷键**：支持键盘操作，提升答题效率
- ✅ **结果分享**：一键分享测试结果

## 使用方法

1. **直接打开**：用浏览器打开 `index.html` 文件即可开始使用

2. **本地服务器**（推荐）：
   ```bash
   # 使用Python启动简单的HTTP服务器
   python -m http.server 8000

   # 或使用Python 2
   python -m SimpleHTTPServer 8000

   # 然后在浏览器访问
   http://localhost:8000
   ```

3. **部署到服务器**：将所有文件上传到Web服务器即可

## 测试说明

### MBTI四个维度

1. **E-I（外向-内向）**：能量来源
   - E (Extraversion): 外向型，从外部世界获得能量
   - I (Introversion): 内向型，从内在世界获得能量

2. **S-N（感觉-直觉）**：信息获取方式
   - S (Sensing): 感觉型，关注具体事实和细节
   - N (Intuition): 直觉型，关注整体和未来可能性

3. **T-F（思考-情感）**：决策方式
   - T (Thinking): 思考型，基于逻辑和客观分析做决定
   - F (Feeling): 情感型，基于价值观和人际影响做决定

4. **J-P（判断-感知）**：生活方式
   - J (Judging): 判断型，喜欢有计划、有条理的生活
   - P (Perceiving): 感知型，喜欢灵活、自发的生活

### 16种性格类型

- **分析家型**：INTJ, INTP, ENTJ, ENTP
- **外交家型**：INFJ, INFP, ENFJ, ENFP
- **守护者型**：ISTJ, ISFJ, ESTJ, ESFJ
- **探险家型**：ISTP, ISFP, ESTP, ESFP

## 键盘快捷键

- **数字键 1-5**：快速选择答案（1=非常同意，5=非常不同意）
- **左箭头 ←**：返回上一题
- **右箭头 →**：进入下一题（需先选择答案）
